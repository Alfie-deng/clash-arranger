# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-09-18

Experimental first public release of Clash Arranger (Clash 节点编排器). The project does **not** promise zero
interruption. Treat it as a library and operator toolkit, not an appliance.

### Added

- Versioned JSONL sample schema and fixture-mode sampling.
- Configurable half-open ranking windows with frozen tag cutoffs.
- Provider / failure-domain mixing with short-pool degrade.
- Two-round controller probes, isolation, and mass-failure escape.
- Sustained paired-throughput promotion.
- Text-level YAML group transactions with rollback, CAS, and downstream sync.
- Workstation (weekday) and router (daily) example profiles.
- `doctor`, `sample`, `rank`, `plan`, `apply`, `watch`, and `status` commands.
- macOS LaunchAgent and Linux systemd/cron example units.
- Chinese and English guides.
